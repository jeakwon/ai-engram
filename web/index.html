ai-engram

Isolate what a model knows.
Then edit it.

Minimal, closed-form covariance-based engram extraction for editing HuggingFace LLMs. Forward-only statistics, one pseudo-inverse per layer — no gradient descent, no labels.

GitHub PyPI Quickstart
pip install "ai-engram[llm]"
W_engram = W · Σ_target · pinv(Σ_total) the slice of a layer's weights driven by the target data — subtract α·W_engram to remove it

Why ai-engram

🧮

Closed-form

One matrix product and a pseudo-inverse per layer. No optimization loop, no labels, no training.

⚡

Forward-only

Covariances gathered with forward pre-hooks — no backward pass, half the memory and compute of a training step.

🤗

HF-native

Works on Llama, Mistral, Qwen, Gemma, Phi… and the GPT-2 family (Conv1D) out of the box.

➕

Bias-correct

Bias absorption is automatic: affine layers y=Wx+b are edited exactly via homogeneous coordinates.

🎯

Selective

Answer-token masking and per-layer targeting — edit only the knowledge and the modules you mean to.

🪶

Tiny

A few hundred lines. from engram import EngramEditor and you're editing.

How it works

Collect

collect_statistics()

Forward pre-hooks accumulate Σ = Σ xᵀx per layer over the forget set and the total set. No backward pass.

Compute

compute_engram_weights()

One pseudo-inverse per layer yields W_engram (and a bias engram for affine layers).

Apply

W − α·W_engram

A single subtraction removes the target knowledge and preserves the rest. (Milestone 2)

Quickstart

# any nn.Linear model

from engram import EngramEditor, EditorConfig

editor = EngramEditor(model, EditorConfig())

target = editor.collect_statistics(forget_loader)
total  = editor.collect_statistics(total_loader)

weight_engrams, bias_engrams = \
    editor.compute_engram_weights(target, total)
# weight_engrams[name].shape == layer.weight.shape

# HuggingFace causal LLM (answer-token masked)

from engram import EngramEditor, EditorConfig, MaskedLinearHandler

editor = EngramEditor(model, EditorConfig(precision=torch.float32))
masked = MaskedLinearHandler()
editor.registry[torch.nn.Linear] = masked

def batch_fn(b):
    masked.current_mask = b["labels"] != -100
    return {"input_ids": b["input_ids"],
            "attention_mask": b["attention_mask"]}

g_forget = editor.collect_statistics(forget_loader, batch_fn=batch_fn)
g_total  = editor.collect_statistics(total_loader,  batch_fn=batch_fn)
weight_engrams, _ = editor.compute_engram_weights(g_forget, g_total)
